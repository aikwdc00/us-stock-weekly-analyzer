# 美股分析工作台 2.0 資料契約

## Evidence

所有對外顯示的數值或文字分析，都應能追溯到一筆 evidence。`kind` 用來區分事實與推論，`status` 用來區分資料是否可用；`unsupported` 不應渲染 UI。

```js
{
    value: 123.45,
    unit: "USD",
    kind: "fact", // fact | calculated | inference | ai
    source: "SEC EDGAR",
    sourceUrl: "https://...",
    asOf: "2026-08-05T00:00:00.000Z",
    reportedPeriod: "FY2025",
    confidence: "high", // high | medium | low
    status: "available", // available | missing | stale | unsupported
    note: "原始申報數值",
}
```

## Data availability

資料欄位必須回傳 capability metadata：

- `supported`: provider 或該公司可能提供此欄位。
- `available`: 已取得可用資料。
- `missing`: 理論上支援，但這次沒有資料。
- `stale`: 有舊資料，但已超過該欄位 TTL。
- `unsupported`: 公司、產業或 provider 不提供此欄位。

UI 僅對 `available`、`missing`、`stale` 渲染資料狀態；`unsupported` 欄位直接隱藏。美股沒有月營收時，財報頁只顯示季度、年度與 TTM 資訊。

## Domain boundaries

- `company`: identity、quote、fundamentals、filings、events、ownership。
- `industry`: classification、economics、demand、supply chain、competition、regulation。
- `watchlist`: user-owned symbol order、tags、research status、review date。
- `comparison`: selected peers and metrics; never implicitly equals the watchlist。
- `research`: thesis、invalidation conditions、notes、evidence references。

## Provider states

Provider registry states are `candidate`, `verified`, `rejected`, and `fallback`. Only `verified` providers may become the primary source. A rejected provider must retain its evaluation reason and must not silently enter production.
